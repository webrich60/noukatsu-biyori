やさしい脳活日和｜10ゲーム GitHub Pages テスト版 v1.2

【内容】
・ゲーム10種類（今日いただいたHTMLコードを元にしたもの）
・フクロウ＋10種類の専用イラストアイコン
・ログイン、Firebase、GAS、Gemini/AI、サブスク決済は一切なし
・ニックネーム、年齢は任意。入力した場合はブラウザのlocalStorageに保存
・音設定とスタンプも端末内に保存
・通信先：なし（GitHub Pagesからファイルを取得するための通信は当然必要）

【GitHub Pagesで公開する手順】
1. ZIPを解凍
2. GitHubリポジトリを新規作成、またはテスト専用の既存リポジトリを使う
3. リポジトリのルートへ index.html と assets フォルダ（中の11画像も含む）をアップロード
4. Settings > Pages > Deploy from a branch > main / (root) > Save
5. https://GitHubユーザー名.github.io/リポジトリ名/ を開いて10種類のゲームを確認

【注意】
既存のFirebase連携版のリポジトリへ上書きしないでください。
端末内保存なので、他端末や別ブラウザにはデータは同期されません。
ブラウザデータ削除やシークレットモードで保存データが消えることがあります。
正式な健康/脳年齢診断機能はありません。

【v1.2 変更点】
トップの音と保存の案内を「ご利用案内・音と保存について」の開閉式に変更。
最初は閉じた状態。タップ/キーボードで開閉できます。ゲーム機能・画像・保存方式はv1.1から変更していません。

【v1.3の変更】ホームの10ゲーム一覧のみ上下スクロール対応。画面全体を動かしにくくし、タブレットは3列。ゲーム処理・ログイン無しは変更なし。
